# Solarized Osaka

A dark Obsidian theme inspired by [Solarized Osaka](https://github.com/craftzdog/solarized-osaka).

## Development

This theme is based on the official [Obsidian sample theme](https://github.com/obsidianmd/obsidian-sample-theme).

Install the dependencies:

```bash
npm install
```

Run the CSS linter:

```bash
npm run lint
```

The theme's styles are defined in `theme.css`.
